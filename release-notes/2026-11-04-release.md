# UniProtKB news

## Changes to UniFIRE in release 2026_04

The 2026_04 UniFIRE release introduces an architectural transition to a Nextflow workflow. Consequently, the `unifire:2026.4-full` Docker image is no longer published. 

To ensure a seamless transition, a new `unifire/nextflow` Docker image is now available with an entrypoint fully compatible with the legacy image, while the `unifire:2026.4-lite` image will continue to be published for the time being.

Moving forward, UniFIRE will adopt semantic versioning, starting with version 3.1.0. Details on using the new Nextflow workflow are available in the repository's README.md file.

To give feedback regarding the new UniFIRE pipeline, please contact unifire@ebi.ac.uk.
